## What is Pinly?

Pinly is a **shared photo sticker book app** for friends, couples, and family. Instead of putting photos into another ordinary shared album, Pinly lets you turn photos into stickers, arrange them freely on a shared canvas, add notes and doodles, react to each other's memories, and keep the latest moments visible with iPhone Home Screen widgets.

Pinly 适合记录那些不一定想公开发布、但又想和重要的人一起留下来的照片和小事：朋友日常、情侣记录、异地合照、旅行照片、生日拼贴、食物分享，以及属于你们自己的共同回忆。

## Features

- **Shared sticker books / 共享贴纸册** — 邀请朋友、伴侣或家人一起维护同一本贴纸册
- **Real-time collaboration / 实时共同编辑** — 多人共同编辑同一画布并同步看到变化
- **Photo stickers / 照片贴纸** — 裁切、抠图、蒙版、拍立得等方式把照片变成贴纸
- **Notes & doodles / 便签与涂鸦** — 用文字、便签和随手画补充照片之外的内容
- **Lightweight reactions / 轻互动** — 点赞、留言，或者在朋友的贴纸旁“涂几笔”
- **iPhone Home Screen widgets / 桌面小组件** — 不打开 App，也能在桌面看到共享贴纸册
- **Private sharing / 私人分享** — 通过手机号、二维码或分享链接邀请，外部申请需要创建者确认
- **Sticker storage / 贴纸存储盒** — 暂时取下的贴纸可以收纳，需要时重新贴回画布

## Ways to use Pinly

People use Pinly for everyday food sharing, long-distance group photos, travel memories, private photo sharing, birthday collages, couple journals, and casual photo collections that do not need to become public social posts.

一些常见玩法：

- 和异地朋友把各自拍到的人像拼成一张“隔空合照”
- 把一趟旅行里每个人拍到的照片整理到同一本贴纸册
- 分享照片给重要的人，而不是发朋友圈
- 把生日照片、祝福、便签和涂鸦拼成一页
- 每天分享吃到的东西、宠物、街景和生活碎片
- 把共同贴纸册放进 iPhone 桌面小组件
